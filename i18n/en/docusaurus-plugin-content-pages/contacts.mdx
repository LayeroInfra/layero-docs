# Contact

**Write to support in the dashboard chat or by email to support@layero.ru.** The first answer from a specialist comes within three
working hours. Support works on working days from 10:00 to 19:00 Moscow time.

## Chat in the dashboard

The chat button is in the bottom right corner of
[app.layero.ru](https://app.layero.ru). If your question is about a specific
project, pick it in the «Обращение по проекту» (Request about a project) line:
the specialist then sees right away what it's about. You can attach
screenshots — paste them, use the paperclip or drag them in.

## Email

[support@layero.ru](mailto:support@layero.ru) — if the dashboard isn't
available or you prefer email. Say which project it's about and what
happened.

## Telegram

The [@layero_support_bot](https://t.me/layero_support_bot) bot sends the specialist's answers to Telegram, and your messages to the bot go into the request that's already open. To connect it, click «Подключить Telegram» (Connect Telegram) in the dashboard chat.

## GitHub

[github.com/LayeroInfra](https://github.com/LayeroInfra) — examples, the
GitHub Action, plugins for AI agents and this documentation. Found a mistake
in an example or in the docs — open an issue right in the repository.

## Response times

The first answer comes within three working hours; only support working hours
count. If a published site doesn't open or builds don't go through, say so at
the start of the request: such requests are handled first. Support isn't on
call around the clock.

Details — on the [Support](/support) page and in the
[technical support terms](https://layero.ru/support-terms).
