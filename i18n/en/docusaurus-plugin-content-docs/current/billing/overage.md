# Overage billing

:::caution[Not available yet]
Extra usage cannot currently be enabled on Free or Pro. Layero does not
charge for usage above plan limits. The earlier draft that described
threshold payments and a separate payment after the period is obsolete.
:::

You can see your limits and current usage on [Usage and limits](./usage).
In the `valya` pilot, reaching a limit triggers the action listed there.
For other organizations, the new usage limits are displayed without
enforcement; existing plan restrictions remain in place.

## Monetary cap

When extra usage launches, the organization owner will be able to set a
maximum amount for usage above the plan in each billing period. Usage will
continue within that cap. Once it is reached, the restriction for each
metric will apply again. Enabling extra usage will require a paid Pro plan,
a saved payment method, and the owner's explicit consent.

## Settlement

The remaining extra usage is planned to be settled with the subscription
renewal after the period's measurements are final. The exact schedule,
handling of yearly or cancelled subscriptions, and receipt details will be
published before charges are enabled. No overage payments are made now.
