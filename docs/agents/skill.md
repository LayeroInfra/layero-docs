# Навык `layero`

**Навык — это инструкция, которую агент читает, когда задача касается
Layero.** В нём три пути агента, команды CLI, события и коды ошибок, правила —
чего не делать. Навык лежит в публичном репозитории
[`LayeroInfra/layero-agents`](https://github.com/LayeroInfra/layero-agents) и
написан на английском, как и все наши инструкции для агентов.

## Что внутри

```
skills/layero/
├── SKILL.md            ← три пути, вход и токен, события CLI, что не делать
└── references/
    ├── json-events.md   ← события и коды ошибок CLI
    ├── layero-json.md   ← файл layero.json: фреймворк, команды, папка результата
    ├── git-providers.md ← GitHub, GitVerse, GitLab, GitFlic, SourceCraft
    └── data-api.md      ← базы и Data API
skills/layero-content-rules/
└── SKILL.md            ← проверка сайта по правилам Layero против фишинга
```

`SKILL.md` отвечает на вопрос «что делать», а подробности лежат в `references/`.
Агент открывает их, только когда они нужны.

Навык `layero-content-rules` — чек-лист по
[правилам Layero](https://layero.ru/rules). Агент проходит его перед
публикацией сайта со входом, оплатой, розыгрышами или формой поддержки.

## Как поставить

Команды — в [таблице установки](./install.md):

- **Агент с поддержкой Agent Skills** — строка «Agent Skill». Команда предложит два навыка: `layero` и `layero-content-rules`. Ставьте оба.
- **Claude Code** — плагин `layero`: оба навыка и MCP-сервер одной командой.
- **Cursor** — плагин из того же репозитория: MCP, правила и навык.
  Ставится в Cursor: **«Customize» → «Plugins» → «Add»**.

## `layero init` и `AGENTS.md`

```bash
npx layero@latest init
```

Команда необязательна — `layero deploy` работает и без неё. Она делает две
вещи:

- дописывает блок о Layero в `AGENTS.md`, `CLAUDE.md` или `.cursorrules` —
  в те из них, что уже есть в проекте. Если нет ни одного, создаёт `AGENTS.md`;
- создаёт файл `.layero/project.json` — связь папки с проектом. Его заполнит
  первая публикация.

Блок — короткая выжимка навыка на 60 строк: три пути, команды, главные события
и коды ошибок, правила. Агент в новой сессии читает его первым и знает, как
публиковать, даже без установленного навыка. За подробностями блок отправляет
на [docs.layero.ru/agents](./index.md) и в навык.

Настройки сборки `init` не записывает: они живут в
[`layero.json`](../build/layero-json.md) или в настройках проекта. Чтобы
не трогать файлы инструкций, добавьте флаг `--skip-agent-docs`.

## Как проверить, что навык работает

Спросите агента: «Как опубликовать этот проект на Layero?» Правильный ответ
начинается с вопроса, подключён ли репозиторий, и не содержит ни `git init`, ни `npm i -g`. Если агент предлагает создать репозиторий на GitHub, он не загрузил навык.
