# Базы данных

**Базы данных Layero — это обычный PostgreSQL рядом с вашими проектами:**
в том же аккаунте, на серверах в Москве. Базу заводят в панели или одной
командой CLI, а проекту она выдаётся кнопкой — строка подключения приедет
в сборку сама.

:::info[Бета-версия]

Базы данных — в бета-версии. Всё, что описано в разделе, уже работает, но интерфейс и отдельные возможности ещё меняются, а страница
может отставать от панели на несколько дней. Заметили расхождение —
напишите нам, это помогает.

Раздел открыт всем организациям: пункт **Базы данных** есть в меню
[панели](https://app.layero.ru), в группе «Сервисы».

:::

## Два размещения

| | Общая база | Выделенная база |
|---|---|---|
| Где живёт | общий сервер Layero | отдельный сервер только под вас |
| Мощность | общий процессор, «Shared CPU» | ядра, память и диск выбираете вы |
| Место | 0,5 ГБ | от 8 до 2 000 ГБ, диск можно увеличить |
| Тариф | только Pro | любой, подписка не нужна |
| Цена | входит в Pro | от 600 ₽ в месяц |
| Без подписки Pro | после grace-периода доступ закрывается, данные удаляются | не зависит от подписки |
| Сколько можно | одна на организацию | сколько нужно |
| Сколько ждать | меньше минуты | 7–13 минут |
| Версия PostgreSQL | 18 | 14–18 на выбор |
| Резервные копии | бесплатно: раз в сутки, до 7 дней | платная опция: 1–14 копий |
| Завести из CLI | да | только в панели |

**Общая база** — чтобы начать: нажали и работаете. Её хватит на прототип,
небольшой сайт или внутренний сервис.

**Выделенная база** — когда нужны гарантированные ресурсы, больше места
или своя версия PostgreSQL. Её можно завести сразу или перенести на неё
общую базу, когда та вырастет.

Подробно о ценах и оплате — [«Тарификация»](./pricing.md), обо всех
ограничениях — [«Лимиты»](./limits.md).

## Что умеет раздел

- **Проект подключается сам.** Выдайте базу проекту — строка подключения
  приедет в переменную `LAYERO_DATABASE_URL`, у проекта будет своя роль в базе.
- **Таблицы и связи** — состав базы по схемам, строки и диаграмма связей
  прямо в панели.
- **SQL-редактор** с закладками, историей и пробой запроса от имени роли
  Data API.
- **Роли и политики RLS** — кто подключается и какие строки видит. Доступ
  можно выдать на срок.
- **Функции** с пробным вызовом и историей версий.
- **Расширения** переключателем: `pgcrypto`, `uuid-ossp`, `citext`,
  `pg_trgm`, `unaccent`, `btree_gin`, `pgvector`.
- **Мониторинг** — место, подключения и нагрузка за час, сутки или неделю.
- **Резервные копии** по расписанию, восстановление кнопкой, скачивание
  обычного дампа PostgreSQL.
- **Доступ по адресам** — снаружи к базе подключаются только адреса
  из вашего списка.
- **[Data API](../data-api/index.md)** — база по HTTP для фронтенда, без
  своего сервера. Data API пока открыт не всем — как получить доступ,
  написано в его разделе.

## С чего начать

1. [Заведите базу](./create.md) — в панели или командой
   `layero db create`.
2. [Подключите её к проекту](./create.md#что-дальше) или
   [подключитесь сами](./connect.md) по строке подключения.
3. Загляните в [работу в панели](./panel.md), чтобы знать, где что лежит.
