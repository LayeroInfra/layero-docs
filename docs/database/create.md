# Как завести базу

:::info[Бета-версия]

Базы данных — в бета-версии: всё, что здесь описано, работает, но интерфейс
и отдельные возможности ещё меняются. Подробнее — на странице
[«Базы данных»](./index.md).

:::

## Из панели

1. Откройте [app.layero.ru](https://app.layero.ru) и выберите организацию.
2. В меню слева — **Базы данных**, в группе «Сервисы».
3. Нажмите **Создать базу**. Откроется окно «Новая база данных».
4. **Название** — любое, до 60 символов. Оно видно только в панели,
   поменять его можно в любой момент.
5. **Тип базы данных** — PostgreSQL. ClickHouse и Valkey помечены «Скоро».
6. **Конфигурация** — [общая база или выделенная](#какую-базу-выбрать).
7. **Версия PostgreSQL** — у общей базы выбирать нечего, у выделенной —
   любая из предложенных, по умолчанию самая свежая.
8. Нажмите **Создать базу**, если база общая, или **Заказать за N ₽/мес**,
   если выделенная.

Если окно открыто со страницы проекта (**Проект → База данных → Создать
базу**), новая база сразу подключится к этому проекту.

### Сколько ждать

**Общая база** готова меньше чем за минуту. Панель скажет, какой адрес
разрешён для подключения снаружи: «Разрешили ваш адрес … — для приложений
на Layero делать ничего не нужно».

**Выделенная база** поднимается **7–13 минут**. Карточка в списке
показывает шаг подготовки и обновляется сама, F5 нажимать не нужно. Окно
можно закрыть: подготовка продолжится.

:::note[Письма не будет]

Уведомления о готовности мы не отправляем — ни на почту, ни в Telegram.
Держите вкладку открытой или зайдите позже: карточка покажет состояние.

:::

### Пароль

Окно создания пароль не показывает. Строка подключения с паролем —
в меню карточки → **Подключить**: там пароль можно показать кнопкой или
сбросить. Подробнее — [«Подключение к базе»](./connect.md).

## Какую базу выбрать

### Общая база

Плитка **Shared CPU** на вкладке «Стандартная». База живёт на общем сервере
Layero: процессор общий, место — 0,5 ГБ, выбирать нечего. Нажали
и работаете.

- Входит в тариф **Pro**, отдельно за неё ничего не списывается.
- **Одна на организацию.** Когда она уже есть, плитки в мастере нет.
- На тарифе Free плитка открывает оформление Pro.

### Выделенная база

Отдельный сервер только под вас. Конфигурацию задают на одной из двух
вкладок справа от заголовка «Конфигурация»:

- **Стандартная** — готовые конфигурации: плитки с ядрами, памятью, диском
  и ценой в месяц;
- **Произвольная** — три ползунка: ядра, память и диск. Границы и шаг
  подписаны под каждым, цена считается сразу.

Выделенная база доступна **на любом тарифе**, подписка Pro для неё
не нужна. Она оплачивается отдельно, раз в месяц. Цены и расчёт
произвольной конфигурации — на странице
[«Тарификация»](./pricing.md#выделенная-база).

### Оплата при заказе

Сумма видна в подвале окна до нажатия кнопки: «N ₽ в месяц»
и ориентировочная цена за день. Знак «?» рядом объясняет, когда спишем:

- **картой** — сумма замораживается сразу и списывается, когда база готова.
  Если база не поднимется, заморозку снимем;
- **другим способом** (СБП, T-Pay, SberPay, ЮMoney, Alfa Pay) — сумма
  списывается сразу при заказе. Если база не поднимется, вернём её
  целиком.

Платит **владелец организации** — тем способом оплаты, что привязан к его
аккаунту. Если способа нет, кнопка называется «Привязать карту»: панель
отправит к привязке и вернёт к заказу с сохранённым выбором.

Нажимая «Заказать за N ₽/мес», вы принимаете
[оферту](https://layero.ru/offer), [условия для
баз](https://layero.ru/databases-terms) и соглашаетесь на ежемесячное
автосписание. Подробно — [«Тарификация»](./pricing.md#как-проходит-оплата).

## Из CLI

```bash
npx layero@latest db create moya-baza
```

Команда ждёт готовности и печатает строку подключения **один раз** —
сохраните её сразу. Потерялась — пароль можно посмотреть в панели:
меню карточки → **Подключить** → «Показать пароль».

Если организаций несколько, CLI возьмёт личную. Командную организацию
укажите явно:

```bash
npx layero@latest db create moya-baza --org moya-komanda
```

Из CLI заводится только **общая** база. Выделенная заказывается в панели:
у неё есть цена, а подтвердить сумму в терминале негде. Все команды —
[«Базы из CLI»](./cli.md).

## Расширения

Расширения включаются у готовой базы, в разделе **Расширения**:
`pgcrypto`, `uuid-ossp`, `citext`, `pg_trgm`, `unaccent`, `btree_gin`
и `pgvector`.
Подробнее — [«Работа в панели»](./panel.md#расширения).

## Что дальше

- **Подключить к проекту.** Строка подключения приедет в сборку сама,
  в переменной `LAYERO_DATABASE_URL`, вписывать её руками не нужно. В панели:
  кнопка «Подключить проект» на карточке базы. Из CLI:
  `layero db connect moya-baza` из каталога проекта.
- **Подключиться напрямую** — [строка подключения, TLS и доступ по
  адресам](./connect.md).
- **Открыть базу по HTTP** без своего сервера — [Data API](../data-api/index.md).

## Если не получилось

| Что видно | Что это значит |
|---|---|
| Плитки Shared CPU нет | Общая база у организации уже есть. Следующую заводите выделенной |
| «база с Shared CPU у организации уже есть» | Ответ CLI на вторую общую базу — то же самое |
| Плитка Shared CPU открывает оформление Pro | Общая база входит только в Pro. Выделенную можно заказать и на Free |
| «Платный инстанс оплачивает владелец аккаунта…» | Заказывать может любой администратор, но платит владелец организации. Попросите его привязать способ оплаты |
| «предыдущий инстанс ещё готовится» | Одновременно идёт только один заказ. Дождитесь готовности первой базы |
| Карточка «не поднялся» с причиной | Создать не вышло, деньги не списаны или возвращены. В меню карточки — «Заказать ещё раз» |
| Подготовка идёт дольше 20 минут | Напишите нам. Через 90 минут заказ снимется сам, и деньги вернутся |

Причину отказа панель пишет обычными словами. Если непонятно, что делать,
скопируйте текст отказа целиком и пришлите нам в чат.
