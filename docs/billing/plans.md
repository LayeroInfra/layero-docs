# Тарифы Free и Pro

В Layero два публичных тарифа: **Free** (бесплатно) и **Pro** (990 ₽/мес).
Тариф действует на уровне аккаунта.

## Что входит

| Возможность | Free | Pro |
|---|---|---|
| Цена | 0 ₽ | **990 ₽/мес** |
| Проекты | до **5** | без лимита |
| Сборки из вебхука | 100/мес | без лимита |
| Раздача на адресе от платформы (`*.layero.app`) | ✅ | ✅ |
| Runtime-приложения (SSR, Streamlit, Gradio) | ✅ | ✅ |
| **Индексация сайта поисковиками** | — | ✅ |
| Кастомные домены | — | ✅ |
| Веб-аналитика | — | ✅ |
| Наблюдаемость и логи | — | ✅ |
| Аудит производительности (Lighthouse/SiteSpeed) | — | ✅ |
| Усиленный runtime-тир | — | ✅ |
| Убрать плашку Layero с сайта | — | ✅ |
| Командные организации | — | ✅ |
| Мест в команде включено | — | 1 |

:::danger[Индексация выключена по умолчанию — у всех]
Каждый новый проект создаётся с `indexing_enabled = false`, и платформа
отдаёт его сайт с заголовком `X-Robots-Tag: noindex, nofollow`. Пока флаг
выключен, сайт **не может появиться** ни в Яндексе, ни в Google — независимо
от того, что написано в вашем `robots.txt`.

Включение — платная возможность: **Настройки проекта → Индексация сайта**,
требует Pro или беты. Выключить можно всегда и на любом тарифе: понижение
тарифа не должно запирать сайт в индексе.

Проверить, что получилось:

```bash
curl -sI https://<адрес-проекта> | grep -i x-robots-tag
# заголовка нет      → сайт индексируется
# noindex, nofollow  → нет
```
:::

:::note[Runtime доступен и на Free]
SSR- и runtime-приложения (Next.js в режиме сервера, Streamlit, Gradio,
Flask) работают на **обоих** тарифах. Pro отличается усиленным
runtime-тиром, а не самой возможностью запускать динамику.
:::

## Места в команде (seats)

Pro включает **1 место**. Дополнительные места в командной организации
стоят **490 ₽/мес** за место. Места нужны только для совместной работы
в [организациях](../team/organizations) — для личных проектов одного места
достаточно.

## Как оплатить

Оплата — через ЮKassa картой, СБП, T-Pay, SberPay, ЮMoney или Alfa Pay:
способ выбирается при привязке. Автопродление ежемесячное. Оформить Pro
можно в дашборде: **Настройки аккаунта → Тариф → Перейти на Pro**.

## Смена тарифа

- **Free → Pro.** Подключается сразу после оплаты; все возможности Pro
  становятся доступны мгновенно.
- **Pro → Free.** Можно отменить автопродление — тариф останется Pro до
  конца оплаченного периода, затем аккаунт перейдёт на Free. Что при этом
  происходит с проектами сверх лимита и кастомными доменами, подробно
  разобрано в статье [Истечение и продление Pro](./lifecycle).

Данные при переходе на Free **не удаляются** — проекты сверх лимита Free
временно приостанавливаются, а не стираются, и восстанавливаются при
возврате на Pro. Подробности — в [следующей статье](./lifecycle).
