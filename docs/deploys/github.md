# GitHub

**Подключите репозиторий с GitHub — и после каждого пуша Layero соберёт сайт.** Layero получает доступ к репозиториям через GitHub App: подключение не
зависит от того, кто его сделал, и переживает смену состава команды.

Другие провайдеры и их отличия — на странице
[«Подключение репозитория»](./git-providers.md).

## Подключение

1. В [панели](https://app.layero.ru) выберите организацию и откройте её
   настройки → «Git» → «Подключить репозиторий» → «GitHub».
2. В окне «Подключить GitHub» выберите аккаунт или организацию GitHub.
3. На GitHub разрешите доступ ко всем репозиториям или к выбранным и
   подтвердите установку.
4. Вернувшись в панель, нажмите «Новый проект» → «Импорт из репозитория»,
   выберите репозиторий и ветку. Основной веткой по умолчанию станет `main`.

Layero сам подпишется на пуши и запустит первую сборку. Подробнее
о приложении — [GitHub App](../team/github-app.md).

## Пуш в основную ветку

Удачная сборка основной ветки сразу открывается по основному адресу
проекта. Чтобы публиковать вручную, выключите «Автоматически публиковать
пуши в…» в настройках проекта — см.
[«Публиковать пуши автоматически или вручную»](./environments.md#публиковать-пуши-автоматически-или-вручную).

## Пуш в другую ветку

Пуш в любую другую ветку собирает превью по адресу
`<проект>-<ветка>.layero.app`. Основной адрес при этом не меняется.
Удаление ветки на GitHub снимает её превью.

Чтобы выложить сборку ветки на основной адрес без слияния с основной веткой,
нажмите у неё в списке деплоев кружок «Сделать основной» или
выполните `npx layero@latest promote <sha>`.

## Первая сборка

Пока удачной сборки нет, по адресу проекта открывается страница «Сайт
скоро появится». После первой удачной сборки адрес работает сразу.
