# Окружения и превью

**У проекта один основной адрес и по превью на каждую ветку.** Пуш
в основную ветку обновляет основной адрес, пуш в любую другую ветку даёт
превью по отдельному адресу и основной адрес не трогает.

## Окружение — это ветка

Пуш в ветку создаёт окружение со своей историей сборок и своим адресом.
У проекта без репозитория одно окружение — `cli`: в него идут все загрузки
из папки.

Загрузка из папки в проект с репозиторием тоже попадает в окружение `cli` и
основной адрес не трогает, пока вы не опубликуете её флагом `--prod`. Выбрать ветку для загрузки из папки нельзя: CLI отклоняет флаг `--branch`.

## Адреса

| | Основной адрес | Превью ветки |
|---|---|---|
| Проект, созданный после 26 июля 2026 года | `<проект>.layero.app` | `<проект>-<ветка>.layero.app` |
| Проект, созданный раньше | `<организация>-<проект>.layero.app` | `<организация>-<проект>-<ветка>.layero.app` |

Адрес начинает работать сразу после первой удачной сборки. Имя проекта
уникально на всей платформе, поэтому адрес может отличаться от имени
папки.

:::tip[Не собирайте адрес по шаблону]
Точный адрес показан на карточке проекта в панели и в выводе
`layero deploy` (поле `url` в режиме JSON). Берите его оттуда.
:::

Когда к проекту подключён [свой домен](../addresses/custom-domains.md),
он показывает то же, что основной адрес. Если нажать у домена «Сделать основным», адрес на `layero.app` будет перенаправлять на него.

## Какая сборка открывается по основному адресу

По основному адресу и по вашим доменам открывается одна сборка. Её меняют
три действия:

- **Пуш в основную ветку.** Удачная сборка сама становится основной.
- **Выбор сборки вручную.** Любую готовую сборку любой ветки можно сделать
  основной: она откроется сразу, без пересборки.
- **Откат.** Кнопка «Откатить» возвращает прошлую основную сборку.

### Публиковать пуши автоматически или вручную

По умолчанию пуш в основную ветку сразу публикуется. Чтобы публиковать вручную: проект → «Настройки» → «Сборка и деплой» → блок
«Публикация на основной адрес» → выключите «Автоматически публиковать пуши в…»
и нажмите «Сохранить».

После этого пуш в основную ветку собирается как обычно, но основной адрес
не меняется, пока вы не опубликуете сборку сами.

### Как выбрать сборку вручную

**В панели:** в списке деплоев — кружок «Сделать основной» у нужной сборки, на странице деплоя — «Сделать активным».

**В CLI:**

```bash
npx layero@latest deploys list              # найти нужную сборку
npx layero@latest promote a3f9c2b           # сделать её основной
```

Без аргумента `promote` берёт последнюю готовую сборку окружения `cli`,
а не основной ветки. Подробно — [`layero promote`](./rollback.md).

### Откат

Кнопка «Откатить» в панели или команда
[`layero rollback`](./rollback.md) возвращает основному адресу прошлую
сборку. Новая сборка не нужна: прошлая открывается почти сразу. Любую другую сборку, которая ещё хранится, можно сделать основной вручную, см. [«Хранение сборок»](./retention.md).

## Превью веток

Превью ветки — это адрес, по которому открывается её последняя удачная
сборка. У превью нет срока годности: оно работает, пока существует ветка и пока его не вытеснили другие превью (см. ниже). Если удалить ветку на GitHub или GitLab, превью снимется само.

Превью открыты всем, у кого есть ссылка. Поисковики их не индексируют:
на превью платформа всегда отдаёт заголовок `X-Robots-Tag: noindex,
nofollow`. На основном адресе такой же заголовок стоит, пока у проекта не
включена [индексация](../billing/plans.md#индексация-поисковиками).

### Сколько превью работает одновременно

Проект раздаёт не больше пяти превью одновременно. Основной адрес в это
число не входит и работает всегда.

Сборку это не ограничивает: шестая ветка собирается как обычно, с логами и историей.

Когда превью становится больше пяти, приостанавливается то, в которое
дольше всех не деплоили. Возраст ветки значения не имеет. Когда превью приостановлено:

- адрес отвечает страницей «Превью приостановлено»;
- ветка, её сборки и история остаются на месте;
- в панели окружение уходит в раздел «Без активного деплоя».

Чтобы вернуть превью, сделайте пуш в эту ветку. Место уступит превью, в которое дольше всех не деплоили.

`layero deploy` сообщает, если новая сборка вытеснила превью другой ветки:

```
! Превью feature/old-checkout приостановлено — этот деплой занял его место
  Вернуть: задеплойте ту ветку снова или откройте панель
```

В режиме JSON это событие `preview_evicted`. Оно приходит раньше `ready`,
чтобы агент узнал о вытесненном превью до того, как сочтёт работу
законченной.

## Пока сборок нет

Пока у проекта нет ни одной удачной сборки, основной адрес показывает
страницу «Сайт скоро появится», а не ошибку 404. То же видно по адресу
превью, пока ветка собирается в первый раз.
