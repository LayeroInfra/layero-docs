# Подключение репозитория

**Layero собирает сайт из репозитория на GitHub, GitVerse, GitLab, GitFlic
и SourceCraft.** Пуш в ветку даёт превью, пуш в основную ветку обновляет сайт. Провайдеры отличаются тем, как подключаются и что умеет их API: например, у SourceCraft сборку запускают вызовом, см. ниже.

## Как подключить

| Провайдер | Как подключается | От кого зависит подключение |
|---|---|---|
| GitHub | [GitHub App](../team/github-app.md) | ни от кого: приложение установлено на аккаунт или организацию GitHub |
| GitVerse | персональный токен | от человека, который выпустил токен |
| GitLab | персональный токен (`glpat-…`), в том числе на своём сервере | то же |
| GitFlic | персональный токен, в том числе на своём сервере | то же |
| SourceCraft | персональный токен (`pv1_…`) | то же |

Провайдер подключается один раз на организацию: настройки организации →
«Git» → «Подключить репозиторий». Выберите сервис и вставьте токен, а для
GitHub — разрешите установку приложения. После этого репозитории сервиса
появятся при создании проекта: «Новый проект» → «Импорт из репозитория».

Токен хранится зашифрованным. У него есть срок: когда он истечёт, сборки
по пушу встанут, а в списке подключений появится пометка «токен
недействителен» — выпустите новый и обновите подключение. Если человек, выпустивший токен, отзовёт его или потеряет доступ к репозиториям у провайдера, сборки организации тоже остановятся. Для команды выпускайте токен от служебного аккаунта.

Для своего сервера GitLab или GitFlic укажите адрес **API**, а не сайта:
`https://gitlab.example.com/api/v4`, `https://api.gitflic.example.com`.
Адрес должен быть публичным и работать по `https`.

## Чем отличаются провайдеры

| | GitHub | GitVerse | GitLab | GitFlic | SourceCraft |
|---|---|---|---|---|---|
| Сборка по пушу | да | да | да | да; если вебхук не создался, заведите его вручную | нет |
| Превью веток | да | да | да | да | нет |
| Свой сервер | нет | нет | да | да | нет |
| Вложенные группы (`group/sub/repo`) | нет | нет | да | нет | нет |

Для GitHub и GitLab удаление ветки само снимает её превью.

У GitFlic лимит — 500 запросов в час на токен. Их делят все, кто пользуется этим токеном, включая сборки Layero. Если проектов много, выпустите для
Layero отдельный токен, которым больше ничего не пользуется.

### SourceCraft: сборка по вызову

У SourceCraft нет вебхуков, поэтому сборки по пушу нет. Запускайте сборку
из CI самого SourceCraft — вызовом адреса, который выдаст команда:

```bash
npx layero@latest hooks create publish --prod
# → https://api.layero.ru/hooks/<токен>
```

POST-запрос на этот адрес запускает сборку из подключённого репозитория. Ещё можно
нажать «Собрать» в панели. API SourceCraft отдаёт только список файлов без
содержимого, поэтому фреймворк определяется по именам файлов в корне:
`package.json`, `vite.config.ts`, `index.html`.

## Что происходит после пуша

1. Провайдер сообщает Layero о пуше.
2. Layero забирает код нужного коммита и собирает проект.
3. Пуш в основную ветку (обычно `main`) обновляет сайт, пуш в другую ветку —
   превью по адресу `<проект>-<ветка>.layero.app`.

Подробно — [«Окружения и превью»](./environments.md).
