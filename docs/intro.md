# Layero

**Layero собирает и публикует ваш сайт или приложение на серверах в России.**
Вы приносите код из репозитория, из папки или через AI-агента, а платформа собирает его и открывает по адресу `<проект>.layero.app`.

## Как опубликовать сайт

- **Из репозитория.** Подключите репозиторий на GitHub, GitVerse, GitLab,
  GitFlic или SourceCraft. Пуш в основную ветку обновляет сайт, пуш в любую
  другую ветку даёт превью по отдельному адресу.
  См. [Подключение репозитория](./deploys/git-providers.md).
- **Из папки.** Команда `npx layero@latest deploy` в папке проекта загружает код, и Layero собирает его у себя. Git не нужен. Без терминала — перетащите
  папку в панели: **«Новый проект» → «Загрузить из папки»**.
  См. [Первый сайт](./getting-started/quickstart.md).
- **Через AI-агента.** Claude Code, Cursor, Codex и другие агенты публикуют
  и обслуживают сайт сами. См. [AI-агенты](./agents/index.md).

## Что ещё умеет платформа

- **Приложения с сервером** — Next.js с серверным рендерингом, серверы на
  Node.js и Python, Streamlit, Gradio. Приложение запускается по первому
  запросу и засыпает, когда к нему не обращаются.
  См. [Runtime-приложения](./runtime/overview.md).
- **Свои домены** с автоматическим HTTPS — на тарифе Pro.
  См. [Свои домены](./deploys/custom-domains.md).
- **Базы данных Postgres** и **Data API** — доступ к базе по HTTP прямо из
  фронтенда. См. [Базы данных](./database/index.md) и [Data API](./data-api/index.md).
- **Скорость и посещаемость** — замер скорости страниц и веб-аналитика.
  См. [Page Speed](./performance/index.md) и [Аналитика](./team/analytics.md).

## Коротко о платформе

| Что | Как устроено |
|---|---|
| Где работает | серверы сборки и раздачи в России |
| Адрес проекта | `<проект>.layero.app` с HTTPS; свой домен — после проверки DNS |
| Чем собирается | Node.js 20, 22 или 24 (по умолчанию 22), Python 3.10–3.13 (по умолчанию 3.12) — см. [Версии Node.js и Python](./deploys/runtime-versions.md) |
| Тарифы | Free и Pro, оплата в рублях с баланса организации — см. [Тарифы](./billing/plans.md) |
