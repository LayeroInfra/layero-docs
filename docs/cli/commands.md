# Все команды

**Все команды запускаются через `npx layero@latest <команда>`.** Подробная
справка по любой — `npx layero@latest <команда> --help`. У большинства
команд есть флаг `--project <id или слаг>`: без него берётся проект, к
которому привязана текущая папка.

## Вход и аккаунт

| Команда | Что делает |
|---|---|
| `login` | войти через браузер; с `--no-browser` — только напечатать ссылку |
| `logout` | удалить вход с этой машины |
| `whoami` | показать, под каким аккаунтом вы вошли |
| `username <имя>` | задать имя пользователя — адрес личной организации. Для агентов и CI |
| `orgs list` | организации, в которых вы состоите |
| `token create <имя>` | выпустить долгоживущий токен для CI и агентов; права — флагом `--scope`, например `read,deploy,admin` |
| `token list` | выпущенные токены: имя, права, последнее использование |
| `token revoke <id>` | отозвать токен; отзыв действует сразу |
| `token set <токен>` | сохранить на этой машине токен, выпущенный в другом месте |

Как войти и где хранится вход — [«Установка и вход»](./install.md).

## Публикация

| Команда | Что делает |
|---|---|
| `deploy` | упаковать папку и опубликовать; `--dry-run` — только показать план. [Подробно](../deploys/deploy.md) |
| `init` | дописать блок о Layero в `AGENTS.md`, `CLAUDE.md` или `.cursorrules` — [подробно](../agents/skill.md#layero-init-и-agentsmd) |
| `link <id или слаг>` | привязать текущую папку к существующему проекту |
| `claim status [код]` | состояние временного сайта, созданного с `deploy --claim` |
| `claim accept [код]` | открыть страницу, на которой сайт забирают в аккаунт |

## Проекты и окружения

| Команда | Что делает |
|---|---|
| `projects list` | ваши проекты |
| `projects create --repo <провайдер>:<владелец>/<репозиторий>` | создать проект из подключённого репозитория: пуш в ветку — превью, пуш в основную ветку — основной адрес |
| `projects delete <id или слаг>` | удалить проект — **необратимо** |
| `envs list` | окружения проекта и их адреса |
| `sources list` | провайдеры Git и подключения организации |
| `sources connect <провайдер>` | подключить провайдера персональным токеном |
| `sources repos <id подключения>` | репозитории, которые видит токен подключения |

`projects delete`, `domains remove` и другие необратимые команды работают при входе через `login`; токену CI для них нужны права `admin`.

## Сборки, откат и диагностика

| Команда | Что делает |
|---|---|
| `deploys list` | последние сборки основной ветки, `--branch` — другой ветки |
| `rollback` | вернуть прошлую сборку; `--deploy` — конкретную |
| `promote [сборка]` | сделать сборку основной; без аргумента берёт последнюю сборку окружения `cli` |
| `logs` | лог сборки; `--runtime` — лог работающего приложения, `--tail <n>` — сколько строк |
| `diagnose` | объяснить, почему сборка в таком состоянии: причина, лог вокруг ошибки, состояние приложения |
| `source [сборка]` | скачать исходники загрузки ZIP-файлом, `--url` — только ссылка |

Подробно — [«Откат и выбор сборки»](../deploys/rollback.md).

В списке `deploys list` у каждой сборки есть источник: `cli` — загрузка
из папки, `push` — пуш в репозиторий или хук, `manual` — запуск кнопкой
«Собрать заново» в панели.

## Настройки проекта

| Команда | Что делает |
|---|---|
| `env list` | имена переменных окружения и длина значений |
| `env set KEY=value …` | задать переменные, не трогая остальные |
| `env unset KEY …` | удалить переменные |
| `domains list` | домены проекта |
| `domains add <домен>` | подключить домен и показать записи DNS |
| `domains verify <домен>` | проверить DNS сейчас, не дожидаясь фоновой проверки |
| `domains primary <домен>` | сделать домен основным: адрес на `layero.app` будет перенаправлять на него |
| `domains remove <домен>` | отключить домен — **необратимо** |
| `hooks list` | хуки деплоя проекта |
| `hooks create <имя>` | создать хук: адрес, POST-запрос на который запускает сборку. Для CMS, cron и внешнего CI |
| `hooks delete <id>` | отозвать хук: адрес сразу перестаёт работать |

Подробно: [переменные окружения](../build/env-vars.md),
[свой домен](../addresses/custom-domains.md).

## Аналитика и скорость

| Команда | Что делает |
|---|---|
| `analytics status` | подключена ли Яндекс Метрика |
| `analytics connect` | подключить Метрику: команда печатает ссылку, доступ вы выдаёте в браузере |
| `analytics stats` | посещаемость: итоги, динамика, источники, устройства, страницы |
| `analytics disconnect` | отключить Метрику |
| `perf check` | замерить скорость основной ветки, `--wait` — дождаться результата |
| `perf show` | последний замер и сравнение с прошлой сборкой |

## Базы данных и Data API

| Команда | Что делает |
|---|---|
| `db list`, `db create`, `db connect`, `db disconnect`, `db sql`, `db delete` | базы организации — [подробно](../database/cli.md) |
| `data enable` | включить Data API для базы |
| `data env` | переменные `VITE_` и `NEXT_PUBLIC_` для фронтенда, `--write` записывает их в `.env.local` |
| `data methods` | таблицы и функции, доступные через API, и уровень доступа к каждой |
| `data grant <объект>` | задать уровень доступа: показывает SQL и применяет после подтверждения |
| `data keys` | ключи: список, выпуск, отзыв |
| `data origins` | сайты, которым разрешено обращаться к базе из браузера |
| `data probe <метод> <путь>` | пробный запрос через API: настоящие права и политики, запись откатывается |
| `data auth` | вход пользователей приложения: способы, провайдеры, адреса возврата |
| `data buckets` | бакеты для файлов: список и создание |
| `data secrets` | секреты для HTTP-запросов из SQL, значения не показываются |

Подробно — в разделе [Data API](../data-api/index.md).

## Общие флаги

| Флаг | Что делает |
|---|---|
| `--json` | печатать события JSON по одному на строку — [список событий](../agents/json-events.md) |
| `--debug` | при ошибке напечатать полный стек вызовов |
| `--help` | справка по команде |
| `--version` | версия CLI |

## Переменные окружения CLI

| Переменная | Что делает |
|---|---|
| `LAYERO_TOKEN` | токен для CI и агентов. Если задан, CLI берёт его, а не вход, сохранённый командой `login` |
| `LAYERO_JSON=1` | то же, что `--json` |
