# Установка и вход

**Layero CLI — npm-пакет [`layero`](https://www.npmjs.com/package/layero).
Ставить его не нужно: запускайте через `npx layero@latest`.** Нужен
Node.js 20 или новее.

```bash
npx layero@latest deploy
```

Пишите `@latest`. Без версии `npx` берёт уже установленную копию и не проверяет, вышла ли новая: так можно годами запускать старую версию. Если
всё же поставили пакет в проект (`npm install -D layero`), обновляйте его
сами: `npm install -D layero@latest`.

## Вход

```bash
npx layero@latest login
```

1. CLI печатает ссылку вида `https://app.layero.ru/cli?code=5NFW-K2NG` и
   открывает её в браузере. С флагом `--no-browser` CLI только печатает ссылку.
2. В браузере войдите по коду из письма или через Яндекс ID. Аккаунта нет —
   он создастся при первом входе. Страница называет аккаунт, которому
   выдаёт доступ; если он не тот, там же есть «войти другим».
3. Нажмите «Разрешить доступ». CLI сохранит вход в `~/.layero/config.json`.

Ссылку можно открыть на другом устройстве, поэтому вход работает и в сессии SSH, и в контейнере. Код действует 15 минут. Не успели — запустите `login` ещё раз.

После первого входа CLI может попросить имя пользователя: строчные латинские буквы, цифры и дефис, от 2 до 32 символов. Это адрес вашей личной организации. Если CLI запущен агентом или в CI, спросить некому: задайте имя командой `npx layero@latest username <имя>`.

Под каким аккаунтом вы вошли:

```bash
npx layero@latest whoami
```

Вход действует 7 дней. Выйти — `npx layero@latest logout`: команда удаляет
вход с этой машины. Активные сессии видны в панели, в блоке «Сессии» карточки пользователя. Там же их можно закрыть.

## Токен для CI и агентов

В CI нет браузера, а вход действует 7 дней. Выпустите долгоживущий токен:

```bash
npx layero@latest token create ci
```

`ci` — имя токена. По умолчанию у него права на чтение и деплой. Токен
показывается один раз — сохраните его в секретах CI под именем
`LAYERO_TOKEN`. CLI возьмёт его из переменной окружения сам:

```bash
LAYERO_TOKEN="$LAYERO_TOKEN" npx layero@latest deploy --prod --yes --project my-site
```

Токен не печатайте: всё, что попало в лог CI, видят все, у кого есть
доступ к запускам. Список токенов — `npx layero@latest token list`, отозвать — `npx layero@latest token revoke` или на странице «Токены CLI и CI» в
[панели](https://app.layero.ru/settings/cli). Как устроены права —
[«Из GitHub Actions»](../deploys/github-actions.md#токен).

## Файлы CLI

| Файл | Что в нём |
|---|---|
| `~/.layero/config.json` | вход и адрес API. Создаётся командой `login` |
| `.layero/project.json` | связь папки с проектом. Создаётся первым `deploy` или командой `init` |

`.layero/project.json` заполняет CLI: после первой публикации там
появляются id и адрес проекта, править их не нужно. Настройки сборки
CLI туда не записывает — они живут в [`layero.json`](../build/layero-json.md)
или в настройках проекта.

## `layero init`

Необязательная команда для работы с AI-агентами: дописывает в `AGENTS.md`,
`CLAUDE.md` или `.cursorrules` блок о том, как публиковать на Layero, и
создаёт `.layero/project.json`. Подробно — [«Навык layero»](../agents/skill.md#layero-init-и-agentsmd).
