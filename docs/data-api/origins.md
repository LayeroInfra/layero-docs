# Приём с чужого домена

:::info[Бета-версия]

Data API работает в бета-версии и открыт пока не всем. Как получить доступ
и чего ждать от страниц, написано в [«Что такое Data API»](./index.md).

:::

Браузер не даст странице обратиться к `data.layero.ru`, если её домен не разрешён
базой. Разрешённые домены складываются из двух списков, а для виджетов на чужих
сайтах есть третий режим — «любой сайт».

## 1. Домены подключённых проектов разрешаются сами

Проект, подключённый к базе, получает право звать её из браузера
автоматически: и апекс (`<проект>.layero.app`), и его собственные домены,
и превью веток. Ничего настраивать не нужно.

## 2. Источники приёма — для чужих сайтов

Если форму нужно поставить на сайт, который к базе **не подключён** (сайт
клиента, лендинг на чужой платформе), добавьте его домен в источники приёма:

```bash
npx layero@latest data origins add https://zarya.example --db <база> --note "лендинг клиента"
npx layero@latest data origins list --db <база>     # оба списка сразу
npx layero@latest data origins remove https://zarya.example --db <база>
```

То же — в панели: «Data API» → «Доступ» → «С каких сайтов доступен Data API».
У базы до 50 источников приёма.

🚨 **Это не то же самое, что подключить проект к базе.** Подключение проекта
заводит ему роль с правами на таблицы и строкой подключения для серверного
кода. Источник приёма не выдаёт ни грантов, ни строки подключения: он снимает
ровно один запрет — браузерный.

Что доступно домену из списка, по-прежнему решают ключ, гранты и RLS. Для
приёма заявок это обычно одна публичная функция и ни одной открытой таблицы —
см. [Функции и RPC](./rpc.md).

## 3. Любой сайт — для встраиваемых виджетов

Виджет, который ставят на сотни чужих сайтов (форма обратной связи, чат,
отзывы), в 50 источников не уместится. Для него у базы есть режим «любой
сайт», как у Supabase: шлюз принимает запросы с публичным ключом с любой страницы.

```bash
npx layero@latest data origins add '*' --db <база>     # включить
npx layero@latest data origins remove '*' --db <база>  # выключить
```

В панели это переключатель «Любой сайт» в том же списке.

⚠️ Включая, помните, что защищают тогда только права и политики. Любая страница
интернета сможет читать и писать всё, что открыто гостю, и тратить суточный
лимит запросов базы. Для виджета откройте гостю одну функцию приёма
(`SECURITY DEFINER`, проверка входных данных внутри) и ни одной таблицы.
Адреса возврата после входа «любой сайт» не открывает: они по-прежнему
сверяются со списком.

Если открывать всё нельзя, есть путь без «любого сайта»: на чужой странице
скрипт рисует кнопку, а форма живёт в `iframe` на домене вашего подключённого
проекта и получает данные страницы через `postMessage`.

## Формат

`https://домен` или `https://домен:порт` — так, как это присылает браузер, либо
`*` — любой сайт. Путь и шаблоны вида `https://*.example` не принимаются: путь
в `Origin` не приезжает вовсе. `localhost` и `127.0.0.1` на любом порту разрешены
по умолчанию — и для запросов, и как адрес возврата после входа, как у Supabase.
Выключить можно в разделе «Доступ».

Правка списка применяется за секунды: отказ по устаревшему кешу шлюз
перепроверяет свежим списком, а не отдаёт из кеша.
