# Чего нет

**В Data API нет Realtime, Edge Functions и входящих вебхуков, а у вызовов, файлов и пользователей есть лимиты по тарифу.** Запрос к тому, чего нет, получает отказ с названием возможности, а не молчаливую заглушку. Молчаливое расхождение дороже отсутствия — «работает,
но не так» всплывает у посетителя, а не у разработчика.

## Возможности, которых нет

| Чего нет | Что делать |
|---|---|
| **Realtime** — подписки на изменения | опрос по интервалу |
| **Edge Functions** — исполнение вашего кода у нас | логика в функциях базы; наружу — [HTTP из SQL](./outbound.md) (`net.http_post`) |
| **Входящие вебхуки** — адрес, который принимает запрос чужого сервиса | свой сервер на Layero принимает вебхук и вызывает функцию; варианты — в [HTTP из SQL](./outbound.md#входящие-вебхуки--их-нет) |
| смена почты, SMS, корпоративный SSO | —; второй фактор есть: приложение-аутентификатор (TOTP), `supabase.auth.mfa.*` |
| RS256/JWKS | токены подписаны HS256 секретом базы |
| преобразования картинок, возобновляемая загрузка, S3-протокол | готовьте файл на своей стороне; загрузка и раздача работают |

⚠️ «Edge Functions нет» **не** значит «наружу нельзя». Уведомления в Telegram,
вебхуки и вызовы чужих API делает функция базы через `net.http_post` — см.
[HTTP из SQL](./outbound.md). Нет именно исполнения вашего кода на нашей стороне.

## Границы, о которых лучше знать заранее

| Что | Значение |
|---|---|
| Одновременных запросов к одной базе | общая база — 4 (по 2 на каждый из двух входов), и они общие у Data API и вашего сервера; выделенная — 20 % потолка соединений кластера, не меньше 4. Это же число показывает `layero db list` (`data_api_concurrent`). Сверх — очередь, затем отказ `db_too_busy` |
| Вызовов за месяц | Free — 1 млн (бета), Pro — 10 млн на организацию, общим счётом по всем базам. Действует с 1 декабря на Free и с 17 декабря на Pro; на Pro сверх — 20 ₽ за 1 млн с [дополнительным потреблением](../billing/overage.md), иначе отказ (429) до нового периода |
| Вызовов за сутки | Free — 50 000 (бета), Pro — 1 000 000 на каждую базу — защита от всплеска; сверх — отказ `quota_exceeded` (429) до 03:00 по Москве |
| Пользователей входа у одной базы | Free — 10 000, Pro — 100 000; сверх — новые регистрации закрыты, вошедшие работают |
| Файл в хранилище | до 50 МБ на любом тарифе |
| Хранилище файлов | Free — 1 ГБ (бета), Pro — 10 ГБ в среднем за месяц на организацию, всего не больше 100 ГБ; на Pro сверх — 10 ₽ за ГБ |
| Баз на организацию | общая — одна, выделенных — сколько нужно; см. [«Лимиты» баз](../database/limits.md) |
| Источников приёма у базы | 50 |

Пометка «бета» у цифр Free значит, что они действуют только для участников бета-программы: остальным на Free Data API не включается.

Запросы считаются все: к таблицам, функциям, файлам и HTTP из SQL.
В месячный лимит не идут вызовы, которые не прошли по нашей вине (5xx),
и отказы лимитов (429). Сайты и подключение к базе по протоколу Postgres
эти пределы не трогают. Месячные лимиты и цены — в статье
[«Потребление и лимиты»](../billing/usage.md).

Отдельный код `db_too_busy` означает «перегружены вы», а не «перегружена
платформа»: соседние базы при этом работают.

## Клиент

Для таблиц, функций, входа пользователей и файлов берите
`@supabase/supabase-js`: контракт шлюза с ним совместим.

```js
import { createClient } from "@supabase/supabase-js";

const db = createClient(
  import.meta.env.VITE_LAYERO_DATA_URL,   // https://data.layero.ru/<база>
  import.meta.env.VITE_LAYERO_DATA_KEY,   // pk_live_…
);

const { data } = await db.rpc("menu");
```

Обойтись можно и без пакетов — вызов функции умещается в несколько строк:

```js
const call = (fn, args) =>
  fetch(`${import.meta.env.VITE_LAYERO_DATA_URL}/rest/v1/rpc/${fn}`, {
    method: "POST",
    headers: { "content-type": "application/json",
               apikey: import.meta.env.VITE_LAYERO_DATA_KEY },
    body: JSON.stringify(args),
  }).then((r) => r.json());
```

Пакет `@layero/data` умеет только вызывать функции методом `rpc`. Метод
`call` убран в версии 0.2.0: адреса, на который он ходил, больше нет.
`setToken` подставляет токен в аргумент функции, но роли вошедшего
пользователя не даёт. Для таблиц, фильтров и входа берите supabase-js.
