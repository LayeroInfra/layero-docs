# Первый сайт

**Одна команда в папке проекта — и сайт открыт по своему адресу.**
Репозиторий не нужен: Layero загрузит папку и соберёт её у себя. Понадобится
только Node.js 20 или новее.

Сайт публикует AI-агент? Ему нужны те же команды плюс навык и MCP — см.
[AI-агенты](../agents/index.md).

## 1. Посмотрите, как соберётся проект

```bash
cd my-site
npx layero@latest deploy --dry-run
```

Команда ничего не загружает и не просит войти. Она показывает, какой фреймворк определила, какой командой будет собирать проект и заменит ли
публикация живой сайт. Если приложение лежит в подпапке, команда скажет об
этом и предложит флаг:

```
! Не удалось уверенно определить приложение в этой папке
  This folder has no app of its own; the app is apps/web (vite). Deploy that folder.
  → npx layero@latest deploy --root apps/web
```

Если проект определился неверно, поправьте одно значение в
[`layero.json`](../deploys/layero-json.md) и запустите проверку снова.

## 2. Опубликуйте

```bash
npx layero@latest deploy
```

Если вы ещё не входили, CLI покажет ссылку и код, а затем откроет браузер. Войдите
по коду из письма или через Яндекс ID и подтвердите вход. Ссылку можно открыть на другом устройстве, поэтому вход работает и в сессии по SSH, и в контейнере.
Если имя аккаунта ещё не выбрано, CLI спросит его: латинские буквы, цифры
и дефис.

Дальше CLI упакует папку (без файлов из `.gitignore` и `.layeroignore`) и загрузит её, а платформа соберёт сайт. Лог сборки идёт прямо в терминал.

Первая публикация создаёт проект и запоминает его в файле
`.layero/project.json`. Следующие публикации из этой папки пойдут в тот же
проект.

## 3. Откройте сайт

В конце CLI печатает адрес вида `https://my-site.layero.app`, и сайт по нему
уже открывается. Берите адрес из вывода CLI или из панели: если имя занято,
адрес будет отличаться от имени папки.

## 4. Обновите сайт

Поменяли код — запустите ту же команду:

```bash
npx layero@latest deploy
```

Новая сборка сразу заменит сайт по основному адресу.

:::warning[Каждая публикация из папки сразу видна посетителям]

У проекта без репозитория нет превью: каждый запуск `layero deploy` заменяет живой сайт. Чтобы сначала посмотреть изменения по отдельному адресу, подключите
репозиторий — тогда каждая ветка получает своё превью. Если новая версия оказалась неудачной, верните прошлую командой `npx layero@latest rollback` или кнопкой «Откатить» в панели.

:::

## Без терминала

В панели нажмите **«Новый проект» → «Загрузить из папки»** и перетащите папку
с сайтом. Платформа соберёт её так же, как при `layero deploy`.
